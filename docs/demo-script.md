# Short portfolio demo script

1. Introduce CareConnect AI as a local portfolio demonstration with fictional data.
2. Search the doctor directory by specialty and open a fictional profile.
3. Sign in as the seeded patient, request an available appointment, and show the appointment list.
4. Upload a sample text-based PDF and inspect its extracted keyword/date overview. Explain that scanned PDFs need OCR and that summaries are informational.
5. Sign in as the demo admin to show aggregate platform counts and the no-show evaluation report, calling out that the model uses synthetic data and is not real-world accuracy evidence.
6. Close with the responsive layout and the care access disclaimer.
